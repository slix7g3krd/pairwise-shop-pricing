# pairwise-shop-pricing

限时折扣结束后价格没恢复，折扣结束时间用的是客户端本地时钟，玩家改系统时间就能一直享受折扣；多个折扣叠加时按加法算，折上折变成负数；价格用浮点数存，0.1 加 0.2 出现 0.30000000000000004；结算时四舍五入到分，显示价按元取整，两边差一分钱；库存扣减和下单不在一个事务，超卖后价格回滚但订单还在；同一玩家并发下单，锁只加在客户端；退款按当前价格退，打折时买的装备按原价退；显示价用前端计算，结算价用后端计算，中间隔了一次汇率更新；区域定价表没有版本号，旧客户端缓存了旧价格；改价没有审计日志，运营误操作查不到。gameplay/shop_pricing.py 是核心，tests/test_shop_pricing.py 15个红。要修的是：服务器时间；叠加上限；整数分；统一舍入；库存事务；服务端锁；按成交价退款；同一计算源；区域表版本；审计日志。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
